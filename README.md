Vice Coast Cover Lab — a static offline web app that turns your own photos and a caption into GTA 6-style cover art: multi-panel poster layouts, a Vice City sunset/neon colour grade, bold caption lettering, and PNG export in the common post sizes 1080×1080, 1080×1350 and 1920×1080. Everything runs in the browser from local files; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the app serves `app/` statically and works with no network.
